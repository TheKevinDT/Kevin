# Kevin

Página web hecha con HTML, CSS y JavaScript puro (sin frameworks).

## Estructura del proyecto

```
Kevin/
├── index.html          # Página principal
├── css/
│   ├── styles.css      # Estilos principales
│   └── responsive.css  # Media queries (responsive)
├── js/
│   └── main.js         # Scripts JavaScript
└── assets/
    ├── images/         # Imágenes
    ├── fonts/          # Fuentes
    └── icons/          # Íconos y favicon
```

## Cómo verlo

Simplemente abre `index.html` en el navegador, o sirve el proyecto con:

```bash
npx serve .
# o
python -m http.server 8000
```

## Tecnologías

- HTML5
- CSS3 (con variables y media queries)
- JavaScript (vanilla)
